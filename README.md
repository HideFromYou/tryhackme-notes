## 🧠 Learning Approach

My approach is focused on understanding **why an attack works**, rather than simply following commands.

For each lab or vulnerability, I try to document:

1. **Reconnaissance**
2. **Enumeration**
3. **Vulnerability Identification**
4. **Exploitation**
5. **Privilege Escalation**
6. **Post-Exploitation**
7. **Evidence / Flags**
8. **Lessons Learned**
9. **Remediation / Security Impact**

The goal is to develop a strong **penetration tester mindset** and understand how individual vulnerabilities can be chained together to compromise a system.
