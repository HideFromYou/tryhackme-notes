# ItsyBitsy - TryHackMe

## Overview

ItsyBitsy is an OSINT challenge designed to strengthen investigation skills through open-source intelligence techniques. The room encourages careful information gathering, source validation, and evidence correlation to solve the investigation.

## Objectives

* Perform OSINT reconnaissance.
* Gather publicly available information.
* Validate findings.
* Complete the investigation objectives.

## Skills Learned

* OSINT
* Search engine reconnaissance
* Information validation
* Digital footprint analysis
* Investigation workflow

## Investigation

The challenge requires gathering information from multiple public sources and correlating the collected evidence to identify meaningful relationships.

## Key Takeaways

* Effective investigations depend on careful methodology.
* Always validate information from multiple sources.
* Publicly available information can reveal significant intelligence.

## Tools Used

* Search Engines
* Browser
* WHOIS
* DNS Lookup
