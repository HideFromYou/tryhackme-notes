# Summit - TryHackMe

## Overview

Summit is an OSINT challenge that focuses on collecting, analysing, and validating publicly available information. The room develops investigation methodology and demonstrates the importance of correlating multiple sources before drawing conclusions.

## Objectives

* Gather open-source intelligence.
* Validate collected information.
* Correlate evidence.
* Complete the investigation.

## Skills Learned

* OSINT methodology
* Digital investigations
* Search engine techniques
* Information validation
* Evidence correlation

## Investigation

The assessment requires collecting publicly available information from several online platforms and combining individual findings to build a complete picture of the target.

## Key Takeaways

* Every investigation should follow a structured methodology.
* Information should always be verified before use.
* Small details often lead to valuable discoveries.
* Proper documentation improves investigation quality.

## Tools Used

* Search Engines
* Browser
* WHOIS
* DNS Lookup
