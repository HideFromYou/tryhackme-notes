# The Greenholt Phish - TryHackMe

## Overview

The Greenholt Phish focuses on phishing investigation and incident analysis. The room introduces common techniques used to identify phishing attempts and teaches how to investigate suspicious emails using publicly available intelligence sources.

## Objectives

* Investigate a phishing campaign.
* Identify malicious indicators.
* Analyse email artefacts.
* Document investigation findings.

## Skills Learned

* Email investigation
* Threat intelligence
* Indicator of Compromise (IOC) analysis
* Phishing detection
* Evidence correlation

## Investigation

The investigation includes analysing suspicious email content, validating sender information, inspecting embedded URLs, and identifying malicious infrastructure associated with the phishing campaign.

## Key Takeaways

* Email headers provide valuable forensic evidence.
* Verify domains before trusting email content.
* Combine multiple intelligence sources to improve confidence.

## Tools Used

* Browser
* VirusTotal
* WHOIS
* URL Analysis Tools
* Email Header Analyzer
