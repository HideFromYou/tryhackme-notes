# Checkmate - TryHackMe

## Overview

Checkmate is a Windows security challenge that focuses on system enumeration, privilege assessment, and post-exploitation techniques. The room reinforces the importance of identifying Windows misconfigurations and applying a structured methodology to achieve administrative access.

## Objectives

* Enumerate Windows services and users.
* Identify privilege escalation opportunities.
* Obtain elevated access.
* Complete the room objectives.

## Skills Learned

* Windows enumeration
* User and privilege assessment
* Windows privilege escalation
* Post-exploitation methodology

## Enumeration

The engagement begins with identifying available services, user accounts, scheduled tasks, and system configurations that may expose privilege escalation opportunities.

## Privilege Escalation

Careful local enumeration reveals Windows misconfigurations that can be leveraged to obtain administrative privileges.

## Key Takeaways

* Local enumeration is critical after gaining initial access.
* Windows privilege escalation often depends on system misconfigurations.
* Documentation improves repeatability during assessments.

## Tools Used

* Nmap
* PowerShell
* WinPEAS
* CMD
* Sysinternals
