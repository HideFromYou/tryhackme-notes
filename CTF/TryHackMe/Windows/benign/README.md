# Benign - TryHackMe

## Overview

Benign is a Windows-focused investigation room that introduces defensive analysis, system enumeration, and incident response concepts. Participants analyse system activity to identify malicious behaviour and understand common attacker techniques.

## Objectives

* Investigate suspicious activity.
* Analyse Windows artefacts.
* Identify malicious actions.
* Complete the investigation.

## Skills Learned

* Windows investigation
* Event log analysis
* Process analysis
* Incident response
* Windows forensics

## Investigation

The room focuses on analysing Windows artefacts, system logs, and running processes to identify suspicious behaviour and reconstruct attacker activity.

## Key Takeaways

* Windows logs provide valuable forensic evidence.
* Correlating multiple artefacts improves investigation accuracy.
* Proper documentation supports incident response activities.

## Tools Used

* Event Viewer
* PowerShell
* Sysinternals
* Windows Command Prompt
