# Recruit - TryHackMe

## Overview

Recruit is a web-based challenge focused on reconnaissance and web application assessment. The room encourages participants to identify exposed functionality, analyse the target application, and apply common web penetration testing techniques to achieve the objectives. It reinforces a structured methodology rather than relying on automated exploitation.

## Objectives

* Perform web reconnaissance.
* Enumerate application functionality.
* Identify security weaknesses.
* Exploit the discovered vulnerability.
* Complete the room objectives.

## Skills Learned

* Web reconnaissance
* Directory and content enumeration
* HTTP analysis
* Web application assessment
* Vulnerability identification
* Structured penetration testing methodology

## Enumeration

The assessment begins by identifying the web application's exposed resources and functionality. Careful enumeration of pages, directories, parameters, and responses provides the information required to understand the application's behaviour before attempting exploitation.

## Initial Access

After identifying the vulnerable component, standard web application testing techniques can be applied to gain access to the intended functionality and complete the challenge.

## Key Takeaways

* Thorough enumeration often reveals the attack path.
* Understanding application logic is more valuable than relying solely on automated tools.
* Small misconfigurations can expose significant security weaknesses.
* Following a structured methodology improves both efficiency and accuracy during web assessments.
