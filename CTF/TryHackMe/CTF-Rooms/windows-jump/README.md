# Windows Jump - TryHackMe

## Overview

Windows Jump is a Windows penetration testing room that introduces system enumeration, privilege assessment, and common administrative misconfigurations. The room reinforces a structured approach to Windows exploitation and privilege escalation.

## Objectives

* Perform Windows enumeration.
* Identify privilege escalation opportunities.
* Obtain elevated access.
* Complete the room objectives.

## Skills Learned

* Windows enumeration
* PowerShell usage
* WinPEAS enumeration
* Privilege escalation
* Windows security assessment

## Enumeration

The engagement begins with identifying system information, user privileges, running services, scheduled tasks, and other Windows artefacts that may expose privilege escalation opportunities.

## Privilege Escalation

The room focuses on identifying insecure configurations that can be abused to obtain administrative privileges through careful local enumeration.

## Key Takeaways

* Thorough local enumeration is essential after initial access.
* Windows misconfigurations frequently lead to privilege escalation.
* Following a structured methodology improves assessment quality.

## Tools Used

* Nmap
* PowerShell
* WinPEAS
* CMD
* Windows Utilities
