# Snapped Phish-ing Line - TryHackMe

## Overview

Snapped Phish-ing Line is a phishing investigation room that introduces the fundamentals of email analysis and threat investigation. Participants analyse phishing indicators, inspect email artefacts, and identify malicious infrastructure while following a structured investigation methodology.

## Objectives

* Analyse a suspicious email.
* Identify phishing indicators.
* Investigate malicious infrastructure.
* Correlate collected evidence.
* Complete the investigation.

## Skills Learned

* Email analysis
* Phishing detection
* Header analysis
* Threat intelligence
* IOC identification
* Investigation methodology

## Investigation

The investigation focuses on analysing the phishing email, validating sender information, inspecting links and attachments, and identifying indicators of compromise (IOCs). Evidence gathered throughout the investigation is correlated to understand the attack.

## Key Takeaways

* Never trust email appearance alone.
* Email headers contain valuable forensic information.
* Validate URLs before interacting with them.
* Documentation is essential during phishing investigations.

## Tools Used

* Browser
* Email Header Analyzer
* VirusTotal
* WHOIS
* URL Analysis Tools
