# Anthem - TryHackMe

## Overview

Anthem is a beginner-friendly Windows room that focuses on reconnaissance, web enumeration, credential discovery, and Windows privilege escalation. The room demonstrates how publicly exposed information and system misconfigurations can lead to compromise.

## Objectives

* Enumerate Windows services.
* Gather publicly exposed information.
* Obtain initial access.
* Escalate privileges.
* Capture the required flags.

## Skills Learned

* Windows enumeration
* IIS enumeration
* Credential discovery
* Windows privilege escalation
* File system analysis

## Enumeration

The assessment begins by identifying exposed Windows services and analysing accessible web resources to discover useful information.

## Initial Access

Enumeration findings are combined to obtain an initial foothold on the target Windows system.

## Privilege Escalation

Privilege escalation focuses on identifying insecure permissions and Windows misconfigurations that allow elevated access.

## Key Takeaways

* Public information should never be overlooked.
* Enumeration remains the most important phase.
* Windows privilege escalation depends on careful system analysis.

## Tools Used

* Nmap
* Browser
* Gobuster
* Windows Command Line
* PowerShell
