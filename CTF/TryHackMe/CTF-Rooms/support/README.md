# Support - TryHackMe

## Overview

Support is a Windows challenge that introduces Active Directory concepts, service enumeration, credential discovery, and privilege escalation. The room demonstrates how common enterprise misconfigurations can be leveraged during an internal penetration test.

## Objectives

* Enumerate Windows services.
* Assess Active Directory resources.
* Obtain initial access.
* Escalate privileges.
* Complete the room objectives.

## Skills Learned

* Active Directory enumeration
* Credential discovery
* Windows privilege escalation
* Internal network assessment

## Enumeration

The assessment focuses on identifying domain information, accessible services, and user accounts that may reveal opportunities for further exploitation.

## Initial Access

Enumeration findings are combined to obtain a foothold within the Windows environment.

## Privilege Escalation

Privilege escalation involves analysing Windows and Active Directory configurations for insecure permissions or privilege assignments.

## Key Takeaways

* Active Directory requires comprehensive enumeration.
* Credentials should always be validated carefully.
* Proper methodology reduces missed attack paths.

## Tools Used

* Nmap
* PowerShell
* BloodHound
* WinPEAS
* CMD
