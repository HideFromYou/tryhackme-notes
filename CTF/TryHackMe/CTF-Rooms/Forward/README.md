# Forward

## Overview

Forward is an Easy web-based TryHackMe challenge focused on reconnaissance, web enumeration, and identifying applications hidden behind forwarding and reverse proxy configurations.

The room emphasizes the importance of thorough enumeration before attempting exploitation.

---

## Learning Objectives

- Perform network enumeration
- Enumerate web services
- Discover hidden resources
- Analyze HTTP requests
- Obtain initial access

---

## Skills Practiced

- Network Enumeration
- Web Enumeration
- Directory Discovery
- HTTP Request Analysis
- Reverse Proxy Discovery
- Initial Access

---

## Tools Used

- Nmap
- Gobuster
- Burp Suite
- cURL
- Firefox / Web Browser

---

## High-Level Attack Flow

1. Network Enumeration
2. Web Enumeration
3. Directory Discovery
4. HTTP Request Analysis
5. Reverse Proxy Identification
6. Initial Access

---

## Key Takeaways

- Proper enumeration often reveals hidden attack surfaces.
- Reverse proxy misconfigurations may expose internal applications.
- Careful analysis of HTTP traffic helps identify potential attack vectors.
