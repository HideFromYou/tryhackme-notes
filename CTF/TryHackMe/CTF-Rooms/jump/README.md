# Jump - TryHackMe

## Overview

Jump is a Windows-focused room designed to strengthen enumeration and lateral movement fundamentals. Participants analyse the target environment, identify available attack paths, and apply common Windows penetration testing techniques.

## Objectives

* Enumerate Windows services.
* Identify attack paths.
* Obtain system access.
* Complete the room objectives.

## Skills Learned

* Windows enumeration
* Service analysis
* Credential discovery
* Lateral movement concepts

## Enumeration

The assessment begins by identifying exposed services and analysing system information to discover potential attack vectors.

## Initial Access

Information gathered during enumeration is leveraged to gain an initial foothold using standard Windows penetration testing techniques.

## Key Takeaways

* Enumeration should always drive the attack path.
* Credentials and exposed services require careful validation.
* Windows assessments benefit from a methodical approach.

## Tools Used

* Nmap
* PowerShell
* CMD
* WinPEAS
