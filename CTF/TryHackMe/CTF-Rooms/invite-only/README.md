# Invite Only - TryHackMe

## Overview

Invite Only is an OSINT and reconnaissance challenge that focuses on gathering publicly available information to identify hidden clues and complete an investigation. The room demonstrates how information scattered across multiple online platforms can be correlated to reveal valuable intelligence.

## Objectives

* Perform OSINT investigations.
* Identify publicly available information.
* Correlate findings from different sources.
* Complete the investigation objectives.

## Skills Learned

* Open Source Intelligence (OSINT)
* Search engine reconnaissance
* Social media analysis
* Information correlation
* Digital footprint analysis

## Investigation

The investigation begins by collecting publicly available information from multiple online resources. By analysing usernames, profiles, metadata, and related digital artefacts, enough intelligence can be gathered to continue the investigation.

## Key Takeaways

* Public information can reveal more than expected.
* Always verify findings using multiple sources.
* Structured investigations produce more reliable results.
* Documentation is essential during OSINT engagements.

## Tools Used

* Search Engines
* WHOIS
* DNS Lookup
* Browser
* Social Media Platforms
