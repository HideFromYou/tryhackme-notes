# Tomghost - TryHackMe

## Overview

Tomghost is a Linux challenge focused on web application enumeration, Apache Tomcat assessment, initial access, and Linux privilege escalation. The room introduces common techniques used during real-world penetration testing against web servers.

## Objectives

* Enumerate exposed services.
* Assess the Apache Tomcat service.
* Obtain initial access.
* Escalate privileges.
* Capture the required flags.

## Skills Learned

* Service enumeration
* Apache Tomcat assessment
* Credential discovery
* SSH access
* Linux privilege escalation

## Enumeration

The assessment begins with identifying exposed services and analysing web applications. Particular attention is given to the Apache Tomcat service and associated resources.

## Initial Access

Information gathered during enumeration is used to obtain an initial foothold on the target system using standard penetration testing techniques.

## Privilege Escalation

Privilege escalation involves identifying Linux misconfigurations, insecure permissions, or privileged binaries that allow elevated access.

## Key Takeaways

* Thorough service enumeration is essential.
* Web application assessment often reveals valuable attack paths.
* Linux privilege escalation requires careful local enumeration.

## Tools Used

* Nmap
* Gobuster
* Burp Suite
* SSH
* Netcat
