# Capture The Flag (CTF)

## Overview

This directory contains my Capture The Flag (CTF) notes, write-ups, and learning outcomes from various cybersecurity training platforms.

The purpose of this repository is to document my hands-on experience, reinforce penetration testing concepts, and track my progress as I develop practical offensive security skills.

Current platforms include:

* TryHackMe

Additional platforms such as Hack The Box, Proving Grounds, and others may be added as I continue my cybersecurity journey.

---

## Objectives

* Develop a structured penetration testing methodology.
* Improve enumeration and exploitation techniques.
* Practice Linux and Windows privilege escalation.
* Strengthen web application security assessment skills.
* Build experience through realistic hands-on laboratories.
* Maintain organised technical notes for future reference.

---

## Topics Covered

* Information Gathering
* OSINT
* Network Enumeration
* Web Enumeration
* Initial Access
* Linux Privilege Escalation
* Windows Privilege Escalation
* Active Directory Fundamentals
* Reverse Shells
* Post-Exploitation
* Basic Digital Forensics
* Phishing Investigations

## Repository Structure

Each platform contains individual room or machine write-ups summarising:

* Overview
* Objectives
* Skills Learned
* Enumeration
* Initial Access
* Privilege Escalation (when applicable)
* Key Takeaways
* Tools Used

The write-ups are intended as concise learning notes rather than complete walkthroughs.

## Goal

The goal of this collection is to continuously improve my practical penetration testing skills while maintaining a well-organised portfolio that reflects my progress throughout my offensive security learning path.

## Disclaimer

This repository contains my personal notes and learning outcomes from legal Capture The Flag (CTF) exercises and training environments.

No flags, credentials, passwords, or complete walkthrough solutions are included.
