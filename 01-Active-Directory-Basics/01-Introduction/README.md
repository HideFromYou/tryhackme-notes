## Key Concepts Introduced

### Active Directory

Active Directory is Microsoft's directory service used to simplify the management of devices and users within a corporate environment.

### Active Directory Domain

An Active Directory Domain is a fundamental component of an Active Directory environment.

### Domain Components

An Active Directory Domain is made up of different components that work together to provide centralised management.

### Forests

Forests are an important concept within Active Directory and provide a higher-level structure for organising Active Directory environments.

### Domain Trusts

Domain Trusts are relationships between Active Directory domains that allow domains to establish relationships with one another.
