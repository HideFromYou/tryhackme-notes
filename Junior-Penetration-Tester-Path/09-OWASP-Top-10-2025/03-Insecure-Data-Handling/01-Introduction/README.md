# Introduction

## Overview

This room introduces three **OWASP Top 10:2025** categories that focus on how web applications process **user input**, **protect sensitive data**, and **maintain software integrity**. Rather than examining every OWASP category in detail, this room provides a practical introduction to several of the most common and impactful vulnerabilities found in modern web applications.

Throughout the room, you will learn what each vulnerability is, why it is dangerous, how it can be prevented, and finally exploit vulnerable applications in a controlled lab environment.

The room covers the following OWASP Top 10:2025 categories:

- **A04 – Cryptographic Failures**
- **A05 – Injection**
- **A08 – Software or Data Integrity Failures**

---

## Learning Objectives

After completing this lesson, you should be able to:

- Understand the OWASP categories covered in this room
- Explain why secure data handling is important
- Recognize common Injection vulnerabilities
- Understand the importance of cryptographic security
- Explain why software and data integrity must be protected
- Prepare the practical lab environment

## Main Content

### Room Focus

This room examines vulnerabilities related to:

- Sensitive data protection
- User-controlled input
- Application behavior
- Software integrity

Together, these topics demonstrate how improper handling of data can result in serious security vulnerabilities.

---

### OWASP Categories

The room introduces three OWASP Top 10:2025 categories:

- **A04 – Cryptographic Failures**
- **A05 – Injection**
- **A08 – Software or Data Integrity Failures**

For each category you will:

- Learn the vulnerability
- Understand its impact
- Review prevention techniques
- Exploit the vulnerability in a practical lab

---

### Practical Learning

Unlike purely theoretical lessons, this room includes hands-on exercises.

Students deploy a vulnerable virtual machine and interact with intentionally insecure applications to observe how these vulnerabilities behave in real-world scenarios.

---

### Lab Environment

Before beginning the exercises, you should prepare your lab environment by:

- Starting the AttackBox (or connecting through the TryHackMe VPN)
- Deploying the target virtual machine
- Verifying connectivity before beginning the practical challenges

Having both systems running ensures you have the required tools and access to complete each exercise successfully.
