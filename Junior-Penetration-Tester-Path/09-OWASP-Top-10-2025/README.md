# OWASP Top 10 (2025)

## Overview

This section of the repository contains notes on the **OWASP Top 10 (2025)**, a widely recognized list of the most critical security risks affecting modern web applications. Rather than focusing on individual exploits, these modules explain the security principles behind each vulnerability category, demonstrate common attack scenarios, and present defensive techniques used to build secure applications.

The material combines theory with practical labs, covering topics such as identity and access management, secure application design, cryptography, injection attacks, software integrity, and secure data handling.

---

## Learning Objectives

After completing this module, you should be able to:

- Understand the OWASP Top 10 (2025) categories covered in this repository.
- Explain common web application vulnerabilities.
- Recognize insecure implementation and design patterns.
- Understand authentication, authorization, and accountability principles.
- Identify common Injection and Cryptographic vulnerabilities.
- Apply secure development practices throughout the Software Development Life Cycle (SDLC).

# Module Structure

## 01. IAAA Failures

Focuses on **Identity, Authentication, Authorisation, and Accountability (IAAA)** and how weaknesses in identity management contribute to common OWASP vulnerabilities.

Topics include:

- Identity
- Authentication
- Authorisation
- Accountability
- Broken Access Control
- Authentication Failures
- Logging & Alerting Failures

---

## 02. Application Design Flaws

Examines vulnerabilities introduced through insecure architecture, deployment, and operational practices rather than programming mistakes.

Topics include:

- Security Misconfigurations
- Software Supply Chain Failures
- Cryptographic Failures
- Insecure Design
- Threat Modeling
- Secure-by-Design Principles

---

## 03. Insecure Data Handling

Explores vulnerabilities related to protecting sensitive information and safely processing user-controlled input.

Topics include:

- Cryptographic Failures
- Injection
- Software or Data Integrity Failures
- Secure Data Handling
- Input Validation
- Integrity Verification

# Key Takeaways

- The OWASP Top 10 identifies the most significant security risks affecting modern web applications.
- Secure applications require strong authentication, authorization, and accountability mechanisms.
- Security must be integrated into application architecture, deployment, and development—not added after release.
- Sensitive information should be protected using modern cryptographic practices, secure input validation, and integrity verification.
- Applying secure-by-design principles throughout the Software Development Life Cycle (SDLC) significantly reduces the likelihood of common web application vulnerabilities.
