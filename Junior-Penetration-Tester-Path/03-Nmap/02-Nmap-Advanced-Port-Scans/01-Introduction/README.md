# Introduction

## Overview

This room builds upon the basic Nmap scanning techniques by introducing advanced scan types that manipulate TCP flags, hide the attacker's identity, bypass filtering mechanisms, and provide deeper insight into target systems.

## Learning Objectives

- Understand advanced Nmap scan types
- Learn why multiple scan techniques exist
- Recognize situations where advanced scans are useful

## Skills Practiced

- Advanced Enumeration
- Network Reconnaissance
- TCP/IP Analysis

## Key Takeaways

- No single scan works against every target.
- Different operating systems and firewalls respond differently.
- Advanced Nmap techniques improve reconnaissance while reducing detection.
