# Nmap Advanced Port Scans

## Overview

This room explores advanced Nmap scanning techniques designed to improve stealth, evade filtering devices, gather additional information, and customize scan behavior. These techniques are commonly used during penetration tests when standard scans are insufficient.

## Learning Objectives

- Understand advanced TCP scan techniques
- Learn how different TCP flags affect scan results
- Perform stealthier scans
- Understand spoofing and decoy techniques
- Learn packet fragmentation
- Perform Idle (Zombie) scans
- Increase scan verbosity and diagnostic output

- Advanced scans help bypass basic filtering and improve reconnaissance.
- Nmap provides many options for stealth, customization, and detailed analysis.
