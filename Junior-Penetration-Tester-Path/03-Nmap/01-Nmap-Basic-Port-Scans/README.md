# Nmap Basic Port Scans

## Overview

This room introduces the fundamentals of port scanning with Nmap. You will learn how TCP and UDP ports work, understand common scan techniques, and optimize scan performance.

## Learning Objectives

- Understand TCP and UDP ports
- Learn TCP flags and their purpose
- Perform TCP Connect scans
- Perform TCP SYN scans
- Perform UDP scans
- Improve scan speed and scope
