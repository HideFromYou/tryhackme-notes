# Introduction

## Overview

This room introduces the fundamentals of Nmap port scanning. Before performing advanced enumeration, it is important to understand how ports work, how services listen for connections, and why port scanning is a critical phase of reconnaissance.

## Learning Objectives

- Understand the purpose of port scanning
- Learn how Nmap identifies open ports
- Understand the role of network services
- Prepare for basic scanning techniques

## Skills Practiced

- Reconnaissance
- Service Discovery
- Network Enumeration

## Key Takeaways

- Port scanning is one of the first steps during enumeration.
- Open ports reveal services that may become attack vectors.
- Nmap provides fast and reliable service discovery across TCP and UDP networks.
