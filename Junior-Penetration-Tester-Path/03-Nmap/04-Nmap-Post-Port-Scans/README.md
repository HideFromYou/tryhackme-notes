# Nmap Post Port Scans

## Overview

After discovering open ports, the next step is gathering detailed information about the target. This includes identifying service versions, detecting the operating system, running NSE scripts, and saving scan results for reporting.

## Learning Objectives

- Detect service versions
- Identify operating systems
- Use the Nmap Scripting Engine (NSE)
- Save scan results
- Improve post-scan enumeration

## Key Takeaways

- Enumeration begins after identifying open ports.
- Service versions and OS detection help identify vulnerabilities.
- NSE automates many reconnaissance tasks.
- Saving scan results is essential for reporting.
