# Introduction

## Overview

Host discovery is one of the first stages of reconnaissance. Instead of scanning every possible IP address, Nmap first determines which hosts are online, allowing subsequent scans to focus only on reachable systems.

## Learning Objectives

- Understand host discovery
- Learn why identifying live hosts is important
- Prepare for network enumeration

## Skills Practiced

- Reconnaissance
- Network Enumeration
- Target Identification

## Key Takeaways

- Host discovery reduces scan time.
- Live host identification improves efficiency.
- Nmap supports multiple discovery techniques depending on the network environment.
