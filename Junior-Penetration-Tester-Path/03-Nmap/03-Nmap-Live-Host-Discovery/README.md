# Nmap Live Host Discovery

## Overview

Before scanning ports or enumerating services, it is important to determine which hosts are actually online. This room explores Nmap's host discovery techniques using ARP, ICMP, TCP, UDP, and DNS-based methods to efficiently identify live systems on a network.

## Learning Objectives

- Understand host discovery
- Learn subnetting basics
- Enumerate targets efficiently
- Discover hosts using ARP
- Discover hosts using ICMP
- Discover hosts using TCP and UDP probes
- Perform Reverse DNS lookups
