# 01 - Introduction

## Overview

This module builds on the Python fundamentals covered in the previous **Python: Simple Demo** room.

The previous room introduced the basic concepts needed to create a simple Python program:

- Variables
- Conditional statements
- `while` loops

This room expands those fundamentals and introduces additional Python concepts that are important when building practical Python scripts.

The main topics covered in this room are:

- Data types

- Augmented assignment
- Strings
- Lists
- Dictionaries
- Arithmetic operators
- Comparison operators
- Logical operators
- Membership operators
- `for` loops
- `while` loops
- `range()`
- `break`
- `continue`

## Why These Concepts Matter

When writing security scripts, I will often need to work with different types of data.

Examples include:

~~~text
IP addresses
Ports
Usernames
Passwords
URLs
Logs
Command output
~~~

Python provides the functionality needed to store, manipulate, compare, search, and process this information.
