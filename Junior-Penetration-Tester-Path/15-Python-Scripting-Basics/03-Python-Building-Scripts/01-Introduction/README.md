# 01 - Introduction

## Overview

This room focuses on moving from individual Python concepts into complete, working scripts.

In the previous `Python: Core Concepts` room, I covered the foundations of Python, including data types, strings, lists, dictionaries, operators, and loops.

This room introduces the capabilities needed to turn those concepts into reusable and practical programs.

---

## What This Room Covers

The main concepts covered are:

- Functions
- Error handling
- File I/O
- Libraries
- `pip`
- Combining multiple Python concepts into a complete script

## Practical Project

The concepts from this room are combined into a **Password Strength Checker**.

The program:

~~~text
Load common passwords
        ↓
Ask the user for a password
        ↓
Check the password
        ↓
Calculate a strength score
        ↓
Display feedback
        ↓
Write the result to a log file
~~~

The final program combines concepts from both the `Python: Core Concepts` room and this room.

---

## Security Relevance

These concepts are important when building practical security scripts.

A script may need to:

~~~text
Receive input
    ↓
Process data
    ↓
Reuse code
    ↓
Handle errors
    ↓
Read and write files
    ↓
Use libraries
    ↓
Produce useful results
~~~

This is the transition from learning individual Python features to building complete programs.

The goal of this room is to learn the capabilities that turn Python code snippets into complete scripts.
