# SQL Injection Introduction

## Overview

SQL Injection (SQLi) is one of the most common and impactful web application vulnerabilities. It occurs when user-supplied input is improperly incorporated into SQL queries, allowing attackers to influence database operations.

This room introduces the core concepts behind SQL Injection, explains why these vulnerabilities occur, explores the major SQLi techniques, and discusses common mitigation strategies used to protect database-driven applications.

---

## Learning Objectives

After completing this room, you should be able to:

- Understand how SQL Injection vulnerabilities occur
- Explain how SQL queries interact with user input
- Recognise common SQL Injection attack categories
- Differentiate between In-Band, Blind, and Out-of-Band SQL Injection
- Understand the importance of secure database interaction
- Identify defensive techniques that reduce SQL Injection risk

## Key Takeaways

- SQL Injection occurs when untrusted input becomes part of SQL queries without proper protection.
- Understanding SQL syntax is essential for recognising injection opportunities and defensive weaknesses.
- SQL Injection techniques vary depending on how applications expose database responses.
- Secure development practices such as parameterised queries significantly reduce SQL Injection risk.
- Understanding both offensive techniques and defensive controls is essential for effective web application security testing.
