# Practical: SQL Injection

## Overview

This practical lesson provides hands-on experience applying the SQL Injection concepts introduced throughout the room. It reinforces the theory by allowing learners to observe how different SQL Injection scenarios affect application behaviour in a controlled environment.

The objective is to strengthen analytical skills and develop a structured approach to identifying and understanding SQL Injection vulnerabilities.

---

## Learning Objectives

After completing this lesson, you should be able to:

- Apply SQL Injection concepts in a practical environment
- Observe how applications respond to different SQL Injection scenarios
- Recognise common indicators of SQL Injection vulnerabilities
- Compare multiple SQL Injection techniques in realistic situations
- Develop a systematic methodology for web application testing

---

## Main Content

### Applying Theory in Practice

Practical exercises provide an opportunity to reinforce the concepts introduced throughout the room by observing how web applications interact with backend databases.

Working through realistic scenarios helps connect theoretical knowledge with real-world application behaviour.

---

### Observing Application Responses

During testing, careful observation is essential.

Useful indicators may include:

- Changes in page content
- Authentication behaviour
- Database error messages
- Response timing
- HTTP status codes
- Differences in application functionality

Each observation contributes to understanding how the application processes user input.

---

### Comparing SQL Injection Techniques

The practical environment demonstrates that different SQL Injection categories rely on different forms of application feedback.

Depending on the scenario, assessments may involve:

- In-Band SQL Injection
- Blind SQL Injection
- Behaviour-based analysis
- Response timing analysis

Selecting the appropriate approach depends on how the application communicates with its database.

---

### Building a Testing Methodology

Successful security assessments require consistency.

A structured methodology includes:

- Understanding application functionality
- Identifying user-controlled input
- Observing application behaviour
- Recording findings
- Comparing responses
- Drawing evidence-based conclusions

Developing repeatable testing habits improves both accuracy and efficiency.
