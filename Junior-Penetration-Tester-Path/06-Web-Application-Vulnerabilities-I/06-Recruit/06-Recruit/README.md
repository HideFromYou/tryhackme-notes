# Recruit

## Overview

**Recruit** is a hands-on TryHackMe challenge that simulates a recruitment management portal. The room focuses on assessing a web application from an attacker's perspective, identifying weaknesses in authentication, authorisation, and application logic, and understanding how multiple vulnerabilities can be combined to gain higher privileges.

Rather than concentrating on a single vulnerability, the room encourages a structured web application assessment methodology.

---

## Learning Objectives

After completing this room, you should be able to:

- Perform reconnaissance against a web application
- Map application functionality and user roles
- Analyse authentication and authorisation mechanisms
- Identify common web security weaknesses
- Understand how vulnerabilities can be chained together
- Appreciate the importance of secure access control

## Key Takeaways

- A systematic assessment helps uncover hidden application functionality.
- Authentication must always be supported by robust authorisation checks.
- Multiple low-severity issues can often be chained into a critical compromise.
- Broken Access Control remains one of the most impactful web application security risks.
- Secure server-side validation is essential for protecting sensitive resources and administrative functionality.
