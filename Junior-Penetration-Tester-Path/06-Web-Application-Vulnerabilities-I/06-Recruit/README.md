# Recruit

## Overview

**Recruit** is a practical TryHackMe room focused on identifying and exploiting common web application vulnerabilities within a recruitment management platform. The objective is to assess the application's security posture, discover weaknesses in its functionality, and demonstrate how multiple vulnerabilities can be combined to achieve privilege escalation.

The room encourages a structured penetration testing methodology, from initial reconnaissance through to access control analysis and privilege escalation, while reinforcing the importance of secure application design.

---

## Learning Objectives

After completing this room, you should be able to:

- Perform reconnaissance against a web application
- Identify insecure application functionality
- Analyse authentication and authorisation mechanisms
- Recognise common web application vulnerabilities
- Understand how multiple weaknesses can be chained together
- Appreciate the importance of secure access control

## Key Takeaways

- Effective web assessments begin with thorough reconnaissance.
- Authentication alone is not sufficient without proper authorisation.
- Small application weaknesses can often be chained into larger compromises.
- Broken access control remains one of the most impactful web application security risks.
- Secure server-side validation is essential for protecting sensitive functionality and user data.
