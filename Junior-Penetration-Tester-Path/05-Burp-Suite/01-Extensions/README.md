# Extensions

## Overview

Burp Suite's extension framework allows users to expand the platform's capabilities beyond its built-in features. Extensions can automate repetitive tasks, integrate third-party tools, enhance analysis, and streamline penetration testing workflows.

This room introduces Burp Suite's extension ecosystem, covering the official BApp Store, Jython support, and the Burp Extender API.

---

## Learning Objectives

After completing this room, you should be able to:

- Understand Burp Suite's extension architecture
- Install and manage extensions
- Navigate the BApp Store
- Explain the purpose of Jython
- Understand how the Burp Extender API enables custom functionality
- Identify when extensions can improve a testing workflow

## Key Takeaways

- Burp Suite can be customised through extensions.
- Extensions improve efficiency by adding specialised functionality.
- The BApp Store provides a trusted source for community and official extensions.
- Jython enables support for Python-based extensions.
- The Burp Extender API allows developers to create custom extensions for specific testing needs.
