# Extensions

## Overview

Burp Suite is designed to be highly extensible, allowing users to enhance its functionality through extensions. These extensions can introduce new features, automate repetitive tasks, integrate external services, or improve existing testing workflows.

The **Extender** component acts as the central hub for installing, managing, and configuring extensions.

## Main Content

### What Are Extensions?

Extensions are software components that add new functionality to Burp Suite without modifying the core application. They allow security professionals to customise the platform according to their workflow and assessment requirements.

Depending on their purpose, extensions may assist with:

- HTTP message analysis
- Request and response modification
- Workflow automation
- Vulnerability research
- Data processing
- Integration with external tools

---

### The Extender Module

The **Extender** module provides a central interface for working with extensions.

Its primary responsibilities include:

- Installing new extensions
- Enabling or disabling extensions
- Removing installed extensions
- Viewing extension status
- Managing extension settings

This modular approach allows Burp Suite to remain lightweight while giving users the flexibility to expand its capabilities when needed.

---

### Supported Development Languages

Burp Suite supports extensions developed in multiple programming languages.

Common options include:

- Java
- Python (via Jython)
- Ruby (via JRuby)

This flexibility enables developers to build custom functionality using languages they are already familiar with.

---

### Why Use Extensions?

Extensions can significantly improve productivity during web application assessments by reducing manual effort and introducing specialised functionality.

Common benefits include:

- Faster testing workflows
- Additional analysis capabilities
- Automation of repetitive tasks
- Improved reporting
- Integration with third-party tools
- Greater customisation

Extensions should enhance manual testing rather than replace critical analysis by the tester.
