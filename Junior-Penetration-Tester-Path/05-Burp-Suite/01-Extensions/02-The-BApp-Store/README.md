# The BApp Store

## Overview

The **BApp Store** is Burp Suite's built-in repository for extensions. It provides a convenient way to discover, install, and manage community and PortSwigger-developed extensions without leaving the Burp Suite interface.

Using the BApp Store simplifies the process of expanding Burp Suite while helping users maintain a consistent and organised testing environment.

---

## Learning Objectives

After completing this lesson, you should be able to:

- Understand the purpose of the BApp Store
- Browse and search for available extensions
- Install and manage extensions directly within Burp Suite
- Recognise different categories of extensions
- Select extensions that support specific security testing tasks

---

## Main Content

### What is the BApp Store?

The BApp Store is Burp Suite's official extension marketplace. It allows users to install additional functionality with only a few clicks, eliminating the need for manual downloads and configuration in many cases.

It contains both official and community-developed extensions designed to improve different aspects of web application security testing.

---

### Installing Extensions

Extensions can be installed directly through the Extender interface.

A typical workflow includes:

1. Open the BApp Store.
2. Browse or search for an extension.
3. Review its description and functionality.
4. Install the extension.
5. Verify that it loads successfully.

Most extensions become available immediately after installation.

---

### Categories of Extensions

Available extensions support many different areas of web security testing, including:

- HTTP message analysis
- Request and response modification
- Passive security analysis
- Active testing assistance
- Authentication testing
- Content discovery
- Reporting enhancements
- Workflow automation

Each extension is designed to address a specific task or improve an existing Burp Suite capability.

---

### Managing Installed Extensions

Installed extensions can be managed from the Extender module.

Common management tasks include:

- Enabling or disabling extensions
- Updating installed extensions
- Removing unused extensions
- Viewing extension information
- Troubleshooting compatibility issues

Keeping only the extensions required for current assessments helps maintain an efficient and stable workspace.
