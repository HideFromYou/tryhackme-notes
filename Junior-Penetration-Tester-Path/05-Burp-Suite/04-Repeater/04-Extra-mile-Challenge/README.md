# Extra-mile Challenge

## Overview

The **Extra-mile Challenge** is designed to reinforce the manual testing techniques learned throughout the Repeater module. It encourages testers to investigate application behaviour by modifying requests, analysing responses, and experimenting with different inputs in a controlled environment.

Rather than introducing new functionality, this challenge focuses on applying existing knowledge to solve realistic web application testing scenarios.

---

## Learning Objectives

After completing this lesson, you should be able to:

- Apply the complete Repeater workflow independently
- Modify HTTP requests with confidence
- Analyse application responses for meaningful differences
- Develop a systematic approach to manual testing
- Improve problem-solving during web application assessments

---

## Main Content

### Planning the Test

Before sending modified requests, it is important to understand the application's behaviour and identify which parts of the request are suitable for testing.

A clear objective helps determine what should be modified and what responses should be monitored.

---

### Performing Manual Testing

Repeater allows requests to be adjusted and resent repeatedly while maintaining complete control over every request.

Common testing activities include:

- Editing request parameters
- Modifying headers
- Changing cookies
- Adjusting request bodies
- Testing alternative values

Making controlled changes simplifies response analysis.

---

### Analysing Responses

Each response should be carefully reviewed for indicators that suggest different application behaviour.

Useful observations include:

- HTTP status codes
- Response headers
- Response size
- Error messages
- Redirect behaviour
- Changes in returned content

These differences often reveal how the application validates and processes user input.

---

### Developing a Methodology

Successful manual testing relies on consistency.

Testing one modification at a time, documenting observations, and comparing responses helps produce reliable and repeatable results throughout an assessment.
