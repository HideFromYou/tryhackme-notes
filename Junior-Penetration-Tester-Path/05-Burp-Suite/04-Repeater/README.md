# Repeater

## Overview

Burp Suite Repeater is a manual testing tool that allows security professionals to modify and resend HTTP requests without repeatedly interacting with the target application. It provides complete control over request editing and enables immediate inspection of server responses.

This room introduces Repeater's interface, request modification capabilities, response analysis features, and practical use cases during web application security assessments.

---

## Learning Objectives

After completing this room, you should be able to:

- Understand the purpose of Burp Suite Repeater
- Modify and resend HTTP requests manually
- Analyse server responses efficiently
- Use the Analysis Toolbar to inspect responses
- Apply Repeater during practical web application testing

## Key Takeaways

- Repeater enables manual testing by allowing HTTP requests to be modified and resent.
- Immediate response analysis helps identify application behaviour after each change.
- The Analysis Toolbar simplifies response inspection.
- Repeater is an essential tool for validating findings discovered during web application security assessments.
- Combining manual testing with careful response analysis improves the accuracy of security testing.
