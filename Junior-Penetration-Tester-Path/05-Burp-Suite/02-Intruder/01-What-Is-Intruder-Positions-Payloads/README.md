# What Is Intruder: Positions & Payloads

## Overview

This lesson introduces Burp Suite Intruder and its core building blocks: **positions** and **payloads**. Understanding how Intruder identifies where to insert data and what values to use is essential before performing automated web application testing.

---

## Learning Objectives

After completing this lesson, you should be able to:

- Understand the purpose of Burp Suite Intruder
- Identify request positions
- Understand payloads and payload sets
- Explain how positions and payloads work together
- Prepare requests for automated testing

## Skills Practiced

---

## Key Takeaways

- Intruder automates repetitive HTTP request testing.
- Positions determine where payloads are inserted.
- Payloads determine what data is inserted.
- Every Intruder attack begins with correctly configuring positions and payloads.
