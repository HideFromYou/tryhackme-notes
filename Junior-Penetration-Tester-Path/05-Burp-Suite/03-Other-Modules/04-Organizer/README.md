# Organizer

## Overview

The **Organizer** module in Burp Suite helps testers manage and organise HTTP requests collected during a web application assessment. As testing sessions grow larger, keeping track of interesting requests, endpoints, and observations becomes increasingly important.

Organizer provides a central location for storing, categorising, and reviewing requests, making assessments more structured and efficient.

## Main Content

### What is Organizer?

Organizer is a Burp Suite utility that allows testers to collect and manage important HTTP requests during an assessment.

Instead of repeatedly searching through Burp's history, relevant requests can be stored for quick access throughout the testing process.

---

### Organising Requests

Organizer helps group and review requests that may require additional investigation.

Examples include:

- Authentication requests
- API endpoints
- Interesting parameters
- Administrative functionality
- Requests associated with potential vulnerabilities

---

### Improving Workflow

During large assessments, hundreds or even thousands of requests may be generated.

Organizer helps reduce unnecessary searching by keeping important requests readily available, allowing testers to focus on analysis rather than navigation.

---

### Common Use Cases

Organizer is commonly used for:

- Saving interesting requests
- Tracking assessment progress
- Managing testing workflows
- Collecting evidence for reports
- Revisiting important application endpoints
