# Sequencer

## Overview

The **Sequencer** module in Burp Suite is used to evaluate the quality of randomness in tokens generated by web applications. Many applications rely on randomly generated values for session identifiers, CSRF tokens, password reset links, and other security mechanisms. Sequencer helps determine whether these values provide sufficient unpredictability.

By collecting and statistically analysing large numbers of tokens, Sequencer assists in identifying weaknesses that could affect application security.

## Main Content

### What is Sequencer?

Sequencer is a Burp Suite utility that performs statistical analysis on tokens generated by a web application.

Rather than examining individual values, it analyses large collections of tokens to determine whether sufficient randomness exists.

---

### Token Collection

Before analysis begins, Sequencer gathers multiple samples of a selected token.

Common examples include:

- Session identifiers
- CSRF tokens
- Password reset tokens
- API tokens
- Authentication cookies

Collecting a sufficient number of samples improves the accuracy of the statistical analysis.

---

### Randomness Analysis

After collecting tokens, Sequencer performs a series of statistical tests to evaluate their randomness.

These tests help identify whether token generation appears predictable or whether the application is producing values with sufficient entropy.

---

### Common Use Cases

Sequencer is commonly used for:

- Session token evaluation
- Authentication token analysis
- CSRF token assessment
- Randomness validation
- Security mechanism verification
