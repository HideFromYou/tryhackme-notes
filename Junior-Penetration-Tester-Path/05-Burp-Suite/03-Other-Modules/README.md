# Other Modules

## Overview

This room introduces several additional modules available in Burp Suite that assist with data analysis, comparison, randomness testing, and workflow organization. While they are not used as frequently as Proxy, Repeater, or Intruder, these tools provide valuable functionality during web application security assessments.

Understanding when and how to use these modules helps streamline testing and improve the overall assessment process.

---

## Learning Objectives

After completing this room, you should be able to:

- Understand the purpose of Burp Suite Decoder
- Compare HTTP messages using Comparer
- Evaluate randomness with Sequencer
- Organize testing tasks using Organizer
- Select the appropriate Burp module for different scenarios

## Key Takeaways

- Burp Suite contains several utility modules beyond its primary testing tools.
- Decoder simplifies data transformations and encoding tasks.
- Comparer helps identify differences between requests and responses.
- Sequencer evaluates the quality of random tokens generated by applications.
- Organizer assists with managing requests and maintaining an efficient testing workflow.
