# Comparer

## Overview

The **Comparer** module in Burp Suite is designed to identify differences between two pieces of data. It allows testers to compare HTTP requests, HTTP responses, tokens, encoded values, or any other text-based content to quickly highlight changes that may not be immediately visible.

Comparer is particularly useful when analysing application behaviour before and after modifying requests.

## Main Content

### What is Comparer?

Comparer is a Burp Suite utility that performs side-by-side comparisons between two selected items.

Instead of manually inspecting requests or responses, Comparer highlights similarities and differences, making analysis faster and more accurate.

---

### Comparing Data

Comparer supports comparisons of various types of information, including:

- HTTP requests
- HTTP responses
- Headers
- Parameters
- Tokens
- Encoded or decoded data
- Plain text

This flexibility makes it useful throughout the testing process.

---

### Comparison Methods

Comparer provides different viewing modes to help analyse changes efficiently.

These views allow testers to quickly locate modified values, missing fields, or unexpected responses without manually reviewing every line.

---

### Common Use Cases

Comparer is commonly used for:

- Comparing responses before and after modifying a request
- Identifying changes in authentication tokens
- Analysing parameter modifications
- Verifying application behaviour
- Detecting subtle differences in server responses
