# Summary

## Overview

This room covered common attacks against network protocols and the technologies used to defend modern communications.

## Topics Covered

- Sniffing
- MITM
- TLS
- SSH
- Password Attacks

## Skills Developed

- Network Security
- Secure Communications
- Authentication Security
- Attack Mitigation

## Key Takeaways

- Plaintext protocols are inherently insecure.
- TLS and SSH provide secure alternatives.
- Strong authentication and encryption are fundamental security controls.
