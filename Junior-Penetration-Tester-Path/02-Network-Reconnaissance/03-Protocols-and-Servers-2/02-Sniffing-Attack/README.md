# Sniffing Attack

## Overview

A sniffing attack captures network traffic to observe transmitted data. If protocols do not use encryption, attackers can read credentials, emails, files, and other sensitive information.

## Learning Objectives

- Understand packet sniffing
- Learn when sniffing is possible
- Identify mitigation techniques

## Common Tools

- Wireshark
- tcpdump

## Skills Practiced

- Packet Analysis
- Network Traffic Inspection
- Protocol Analysis

## Key Takeaways

- Sniffing is effective against plaintext protocols.
- Encryption prevents attackers from reading captured traffic.
- HTTPS, SSH, and TLS greatly reduce this risk.
