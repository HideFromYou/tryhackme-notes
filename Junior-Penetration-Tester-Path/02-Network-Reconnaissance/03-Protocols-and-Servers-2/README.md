# Protocols and Servers 2

## Overview

This room explores common attacks against network protocols and the security mechanisms used to defend against them.

## Learning Objectives

- Understand common protocol attacks
- Learn how TLS protects communications
- Understand SSH authentication
- Explore password attack techniques

- Authentication prevents unauthorized access.
