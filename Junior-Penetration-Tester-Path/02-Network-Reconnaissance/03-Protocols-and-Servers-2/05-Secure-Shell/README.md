# Secure Shell (SSH)

## Overview

SSH provides encrypted remote administration and secure file transfers over untrusted networks.

## Learning Objectives

- Understand SSH authentication
- Learn secure remote administration
- Recognize SSH security benefits

## Default Port

- TCP 22

## Authentication Methods

- Password
- Public Key

## Skills Practiced

- Secure Remote Access
- SSH Fundamentals

## Key Takeaways

- SSH replaces Telnet.
- Public key authentication is more secure than passwords.
- SSH encrypts all communication.
