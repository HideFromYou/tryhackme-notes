# Man-in-the-Middle (MITM) Attack

## Overview

A Man-in-the-Middle attack occurs when an attacker intercepts and potentially modifies communication between two parties without their knowledge.

## Learning Objectives

- Understand MITM attacks
- Learn common attack techniques
- Identify defensive measures

## Common Techniques

- ARP Spoofing
- DNS Spoofing
- Rogue Access Points
- SSL Stripping

## Skills Practiced

- Network Security
- Attack Identification
- Traffic Manipulation

## Key Takeaways

- MITM attacks compromise confidentiality and integrity.
- Certificate validation helps prevent interception.
- TLS significantly reduces MITM risks.
