# POP3

## Overview

POP3 (Post Office Protocol v3) retrieves emails from a mail server to a local client.

## Learning Objectives

- Understand email retrieval
- Learn POP3 commands
- Compare POP3 with IMAP

## Default Port

- TCP 110

## Common Commands

- USER
- PASS
- LIST
- RETR
- DELE
- QUIT

## Skills Practiced

- Email Retrieval
- Protocol Analysis

## Key Takeaways

- POP3 downloads emails locally.
- Messages are often removed from the server.
- POP3S provides encrypted communication.
