# Telnet

## Overview

Telnet is a text-based remote administration protocol that communicates over TCP port 23. It is also useful for manually interacting with TCP services during penetration testing.

## Learning Objectives

- Understand the Telnet protocol
- Connect to remote services
- Interact with text-based protocols

## Default Port

- TCP 23

## Skills Practiced

- Remote Service Interaction
- Protocol Analysis

## Key Takeaways

- Telnet sends all data in plaintext.
- It has largely been replaced by SSH.
- It remains useful for testing TCP services manually.
