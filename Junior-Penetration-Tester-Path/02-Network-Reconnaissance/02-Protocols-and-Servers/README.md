# Protocols and Servers

## Overview

This room introduces the most common application-layer protocols used in modern networks. Understanding how these protocols operate is essential for both penetration testing and defensive security.

## Learning Objectives

- Understand common network protocols
- Learn how clients communicate with servers
- Recognize insecure protocol implementations
- Understand secure alternatives

## Key Takeaways

- Most legacy protocols transmit data in plaintext.
- Understanding protocols helps identify security weaknesses.
- Secure alternatives use TLS or SSH to protect communications.
