# Summary

## Overview

This room introduced several core application-layer protocols and demonstrated how they operate at a low level.

## Protocols Covered

- Telnet
- HTTP
- FTP
- SMTP
- POP3
- IMAP

## Skills Developed

- Protocol Analysis
- Manual Service Interaction
- Network Fundamentals
- Security Awareness

## Key Takeaways

- Legacy protocols transmit data in plaintext.
- Secure alternatives use encryption.
- Understanding protocols is essential for penetration testing and network security.
