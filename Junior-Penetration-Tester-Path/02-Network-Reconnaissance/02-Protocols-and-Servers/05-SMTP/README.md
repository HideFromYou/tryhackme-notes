# SMTP

## Overview

SMTP (Simple Mail Transfer Protocol) is responsible for sending email between mail servers and clients.

## Learning Objectives

- Understand email delivery
- Learn SMTP commands
- Recognize security risks

## Default Port

- TCP 25

## Common Commands

- HELO
- EHLO
- MAIL FROM
- RCPT TO
- DATA
- QUIT

## Skills Practiced

- Email Protocol Analysis
- Manual SMTP Interaction

## Key Takeaways

- SMTP handles outgoing email.
- Messages are traditionally sent in plaintext.
- Modern deployments use STARTTLS or SMTPS.
