# Introduction

## Overview

This room introduces several widely used application-layer protocols and demonstrates how they work beneath graphical user interfaces by interacting with them manually.

## Learning Objectives

- Understand common server protocols
- Learn why protocol knowledge is important
- Recognize the risks of cleartext communication

## Skills Practiced

- Network Fundamentals
- Protocol Analysis

## Key Takeaways

- Many legacy protocols still exist in modern environments.
- Protocol knowledge improves both offensive and defensive security skills.
- Cleartext protocols expose sensitive information.
