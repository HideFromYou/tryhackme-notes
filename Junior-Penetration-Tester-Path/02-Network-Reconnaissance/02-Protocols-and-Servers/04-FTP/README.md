# FTP

## Overview

FTP (File Transfer Protocol) enables file uploads and downloads between clients and servers.

## Learning Objectives

- Understand FTP communication
- Learn authentication basics
- Transfer files manually

## Default Port

- TCP 21

## Common Commands

- USER
- PASS
- LIST
- GET
- PUT
- QUIT

## Skills Practiced

- File Transfers
- Service Enumeration

## Key Takeaways

- FTP transmits credentials in plaintext.
- Anonymous FTP may expose sensitive files.
- Secure alternatives include FTPS and SFTP.
