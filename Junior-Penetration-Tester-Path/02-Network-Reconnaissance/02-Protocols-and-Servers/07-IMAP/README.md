# IMAP

## Overview

IMAP (Internet Message Access Protocol) allows email to remain on the server while synchronizing mailboxes across multiple devices.

## Learning Objectives

- Understand IMAP synchronization
- Learn common IMAP commands
- Compare IMAP with POP3

## Default Port

- TCP 143

## Common Commands

- LOGIN
- LIST
- SELECT
- EXAMINE
- FETCH
- LOGOUT

## Skills Practiced

- Email Synchronization
- Mailbox Enumeration

## Key Takeaways

- IMAP stores emails on the server.
- Supports multiple synchronized devices.
- IMAPS secures communication using TLS.
