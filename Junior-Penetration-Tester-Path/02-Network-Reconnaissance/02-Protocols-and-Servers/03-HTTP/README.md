# HTTP

## Overview

HTTP (HyperText Transfer Protocol) is the foundation of web communication, allowing browsers and servers to exchange requests and responses.

## Learning Objectives

- Understand the HTTP request/response model
- Identify common HTTP methods
- Learn basic status codes

## Default Port

- TCP 80

## Common Methods

- GET
- POST
- PUT
- DELETE
- HEAD

## Skills Practiced

- Web Protocol Analysis
- HTTP Inspection

## Key Takeaways

- HTTP is stateless.
- Data is transmitted in plaintext.
- HTTPS secures HTTP using TLS.
