# DNSDumpster

## Overview

DNSDumpster is an OSINT tool that gathers publicly available DNS information about a domain, including subdomains, mail servers and DNS records.

## Learning Objectives

- Discover subdomains
- Identify DNS infrastructure
- Map publicly exposed assets

## Information Collected

- DNS Servers
- MX Records
- Host Records
- Subdomains
- Related IP Addresses

## Skills Practiced

- Passive Reconnaissance
- DNS Enumeration
- Attack Surface Mapping

## Key Takeaways

- DNSDumpster relies on public information.
- It helps identify external infrastructure.
- Useful before active enumeration.
