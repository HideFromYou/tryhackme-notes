# Shodan

## Overview

Shodan is a search engine for Internet-connected devices. It indexes exposed services, banners, operating systems and technologies without interacting directly with the target.

## Learning Objectives

- Search Internet-facing assets
- Identify exposed services
- Gather infrastructure intelligence

## Information Available

- Open Ports
- Service Banners
- Operating System
- SSL Certificates
- Geolocation
- Hosting Provider

## Skills Practiced

- OSINT
- Service Identification
- Attack Surface Analysis

## Key Takeaways

- Shodan indexes publicly accessible devices.
- Banner information can reveal software versions.
- Useful for understanding a target's external exposure.
