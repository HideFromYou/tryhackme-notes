# Introduction

## Overview

Passive reconnaissance gathers information about a target using publicly available sources without sending traffic directly to the target.

## Learning Objectives

- Understand passive reconnaissance
- Differentiate passive and active recon
- Recognize common OSINT sources

## Skills Practiced

- Information Gathering
- OSINT

## Key Takeaways

- Passive reconnaissance is difficult to detect.
- It provides valuable information before active enumeration.
- Good reconnaissance reduces unnecessary scanning.
