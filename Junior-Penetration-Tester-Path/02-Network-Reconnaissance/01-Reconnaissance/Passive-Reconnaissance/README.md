# Passive Reconnaissance

## Overview

Passive reconnaissance collects publicly available information without directly interacting with the target. This approach minimizes detection while providing valuable intelligence before active testing.

## Learning Objectives

- Understand passive reconnaissance
- Collect publicly available information
- Perform DNS enumeration
- Discover exposed assets

## Key Takeaways

- Passive reconnaissance leaves little or no trace.
- Public data can reveal valuable infrastructure details.
- Reconnaissance should always begin with passive techniques.
