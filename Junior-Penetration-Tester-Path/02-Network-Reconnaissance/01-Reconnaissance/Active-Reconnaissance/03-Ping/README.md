# Ping

## Overview

Ping uses ICMP Echo Requests to verify whether a host is reachable and measure response times.

## Learning Objectives

- Verify host availability
- Interpret ping results
- Understand TTL values

## Common Commands

- ping
- ping -c
- ping -4
- ping -6

## Skills Practiced

- Host Discovery
- Network Connectivity Testing

## Key Takeaways

- Ping confirms network reachability.
- Firewalls may block ICMP traffic.
- TTL values can provide OS clues.
