# Putting It All Together

## Overview

Active reconnaissance combines multiple tools to build an accurate picture of the target before moving to enumeration and vulnerability assessment.

## Reconnaissance Workflow

1. Inspect the target with a web browser.
2. Verify host availability using Ping.
3. Discover the network path with Traceroute.
4. Identify services using Telnet or Netcat.
5. Continue with advanced tools such as Nmap.

## Skills Practiced

- Active Reconnaissance
- Information Correlation
- Service Enumeration

## Key Takeaways

- No single tool provides complete information.
- Combining multiple techniques improves accuracy.
- Reconnaissance is the foundation of every penetration test.
