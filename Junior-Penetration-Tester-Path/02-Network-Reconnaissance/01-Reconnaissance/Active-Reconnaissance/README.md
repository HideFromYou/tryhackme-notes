# Active Reconnaissance

## Overview

Active reconnaissance involves directly interacting with a target to collect information about hosts, services and network infrastructure. These techniques provide more accurate results but are detectable by the target.

## Learning Objectives

- Understand active reconnaissance
- Use common network reconnaissance tools
- Identify hosts and services
- Collect information before enumeration

## Key Takeaways

- Active reconnaissance communicates directly with the target.
- Different tools reveal different types of information.
- Combining multiple tools provides a clearer picture of the target.
