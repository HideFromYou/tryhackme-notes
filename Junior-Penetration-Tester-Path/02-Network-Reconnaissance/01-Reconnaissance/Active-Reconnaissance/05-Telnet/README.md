# Telnet

## Overview

Telnet is a legacy remote administration protocol that can also be used for banner grabbing on TCP services.

## Learning Objectives

- Connect to TCP services
- Perform banner grabbing
- Identify running software

## Common Commands

- telnet <IP> 80
- telnet <IP> 21
- telnet <IP> 25

## Skills Practiced

- Banner Grabbing
- Service Identification

## Key Takeaways

- Telnet transmits data in plaintext.
- It is useful for basic banner grabbing.
- SSH has replaced Telnet for secure remote administration.
