# Netcat

## Overview

Netcat (nc) is a versatile networking tool used for connecting to services, listening on ports, banner grabbing and simple file transfers.

## Learning Objectives

- Use Netcat as a client
- Use Netcat as a listener
- Identify services through banners

## Common Commands

- nc <IP> <PORT>
- nc -lvnp <PORT>

## Skills Practiced

- Banner Grabbing
- Port Testing
- Client-Server Communication

## Key Takeaways

- Netcat is more flexible than Telnet.
- It supports both TCP and UDP.
- Commonly used during penetration tests.
