# Traceroute

## Overview

Traceroute identifies the path packets take to reach a destination by revealing each router (hop) between the source and the target.

## Learning Objectives

- Understand packet routing
- Identify intermediate hops
- Detect routing issues

## Common Commands

- traceroute
- tracert (Windows)
- mtr

## Skills Practiced

- Route Discovery
- Network Troubleshooting

## Key Takeaways

- Traceroute reveals every hop to the target.
- High latency or timeouts may indicate filtering or network issues.
- Useful for understanding network topology.
