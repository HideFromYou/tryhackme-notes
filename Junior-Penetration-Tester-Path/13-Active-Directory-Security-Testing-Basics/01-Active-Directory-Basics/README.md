# 01 - Active Directory Basics

## Overview

This folder contains my notes and hands-on work from the
TryHackMe Active Directory Basics module.

The module introduces the fundamental concepts of Microsoft
Active Directory and Windows Domains, including how domains,
users, computers, groups, Organizational Units, authentication,
Group Policies and trust relationships work together in a
corporate environment.

## Topics Covered

- Windows Domains
- Active Directory
- Domain Controllers
- Active Directory objects
- Users and machine accounts
- Security Groups
- Organizational Units (OUs)
- Kerberos
- NetNTLM
- Active Directory Trees
- Active Directory Forests
- Trust Relationships
- Child Domains
- Creating a new Domain Controller
- Managing users in AD
- Delegation
- Domain-joining computers
- Managing computers in AD
- Group Policy Objects (GPOs)
- SYSVOL
- Foreign Forest Trusts
- Cross-forest resource access

## Module Structure

### 01 - Introduction
Basic introduction to Active Directory, domains, forests
and trust relationships.

### 02 - Windows Domains
Understanding Windows Domains, Domain Controllers and
centralized administration.

### 03 - Active Directory
Exploring AD objects, users, computers, groups and
Organizational Units.

### 04 - Authentication Methods
Understanding Kerberos and NetNTLM authentication.

### 05 - Trees, Forests and Trusts
Learning how domains are organized into trees and forests
and how trust relationships work.

### 06 - Creating a New Domain
Creating a child domain and promoting a server to a
Domain Controller.

### 07 - Managing Users in AD
Managing users, OUs and delegated administrative permissions.

### 08 - Domain-Joining a Computer
Joining a Windows computer to an Active Directory domain.

### 09 - Managing Computers in AD
Organizing domain computers into appropriate OUs for
centralized management.

### 10 - Group Policies
Creating and applying Group Policy Objects to users and
computers.

### 11 - Foreign Forest Trust
Creating a trust between separate forests and using it
for cross-forest access.

### 12 - Conclusion
Review of the Active Directory concepts covered throughout
the module.

## Key Takeaways

Active Directory provides centralized management of users,
computers and resources inside a Windows environment.

Understanding the relationship between:

    Users
      ↓
    Groups
      ↓
    Organizational Units
      ↓
    Group Policies
      ↓
    Domains
      ↓
    Forests
      ↓
    Trust Relationships

is essential for understanding both Windows administration
and Active Directory security.
