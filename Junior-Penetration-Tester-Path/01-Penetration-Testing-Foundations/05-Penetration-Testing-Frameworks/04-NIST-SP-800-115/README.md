# NIST SP 800-115

## Overview

NIST SP 800-115 provides a structured approach for planning, executing and reporting information security assessments, particularly within government and enterprise environments.

## Learning Objectives

- Understand NIST methodology
- Learn the assessment lifecycle
- Recognize testing techniques

## Phases

- Planning
- Execution
- Post-Testing

## Skills Practiced

- Security Assessment
- Documentation
- Reporting

## Key Takeaways

- Broad security assessment framework.
- Strong adoption in government environments.
- Emphasizes planning and documentation.
