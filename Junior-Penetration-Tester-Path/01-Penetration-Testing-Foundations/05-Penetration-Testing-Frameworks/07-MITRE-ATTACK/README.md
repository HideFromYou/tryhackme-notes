# MITRE ATT&CK

## Overview

MITRE ATT&CK is a knowledge base that documents real-world adversary tactics and techniques. It complements penetration testing by providing a common language for describing attacker behavior.

## Learning Objectives

- Understand ATT&CK structure
- Learn tactics and techniques
- Map findings to ATT&CK

## Core Concepts

- Tactics
- Techniques
- Sub-Techniques
- ATT&CK Matrix

## Skills Practiced

- Threat Intelligence
- Attack Mapping
- Detection Analysis

## Key Takeaways

- ATT&CK is not a penetration testing methodology.
- It documents real attacker behavior.
- Improves reporting and threat analysis.
