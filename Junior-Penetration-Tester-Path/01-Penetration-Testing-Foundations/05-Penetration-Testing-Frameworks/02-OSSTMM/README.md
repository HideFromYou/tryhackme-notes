# OSSTMM

## Overview

The Open Source Security Testing Methodology Manual (OSSTMM) is a scientific security testing methodology that measures security using repeatable metrics instead of subjective opinions.

## Learning Objectives

- Understand OSSTMM principles
- Learn the five security channels
- Understand Risk Assessment Values (RAV)

## Key Concepts

- HUMSEC
- PHYSSEC
- SPECSEC
- COMSEC
- DATASEC
- Risk Assessment Values (RAV)

## Skills Practiced

- Quantitative Security Assessment
- Security Metrics

## Key Takeaways

- Focuses on measurable security.
- Produces repeatable assessment results.
- Well suited for formal security audits.
