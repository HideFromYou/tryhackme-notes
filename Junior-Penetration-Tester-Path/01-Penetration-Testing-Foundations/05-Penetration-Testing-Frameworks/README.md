# Penetration Testing Frameworks

## Overview

This room introduces the most common penetration testing frameworks used in professional engagements. Each framework provides a structured methodology for planning, executing and reporting security assessments.

## Learning Objectives

- Understand major penetration testing frameworks
- Compare their strengths and use cases
- Learn when each framework should be applied
- Select the appropriate methodology for different engagements

- Framework Comparison

## Key Takeaways

- No single framework fits every engagement.
- Framework selection depends on scope, regulations and client requirements.
- Professional testers often combine multiple frameworks.
