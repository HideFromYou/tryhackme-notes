# ISSAF

## Overview

The Information Systems Security Assessment Framework (ISSAF) is an open-source methodology that provides a structured approach for assessing networks, systems and applications.

## Learning Objectives

- Understand ISSAF methodology
- Learn the assessment lifecycle
- Recognize adversarial progression

## Assessment Stages

- Planning
- Assessment
- Reporting & Cleanup

## Skills Practiced

- Security Assessment
- Attack Methodology
- Risk Evaluation

## Key Takeaways

- Uses a structured attacker mindset.
- Covers the full compromise process.
- Valuable for understanding attack progression.
