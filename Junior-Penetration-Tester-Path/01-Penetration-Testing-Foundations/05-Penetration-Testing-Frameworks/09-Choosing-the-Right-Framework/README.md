# Choosing the Right Framework

## Overview

Selecting the correct framework depends on the engagement scope, target environment, regulatory requirements and client objectives.

## Selection Factors

- Engagement Scope
- Target Technology
- Compliance Requirements
- Team Experience
- Reporting Needs

## Skills Practiced

- Methodology Selection
- Engagement Planning
- Risk Assessment

## Key Takeaways

- There is no universal framework.
- Multiple frameworks are often combined.
- The methodology should fit the client's needs.
