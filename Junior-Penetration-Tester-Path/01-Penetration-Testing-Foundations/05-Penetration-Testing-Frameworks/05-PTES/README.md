# PTES

## Overview

The Penetration Testing Execution Standard (PTES) provides an end-to-end workflow that reflects how professional penetration testing engagements are performed.

## Learning Objectives

- Learn the PTES workflow
- Understand engagement phases
- Recognize reporting requirements

## PTES Phases

- Pre-Engagement
- Intelligence Gathering
- Threat Modeling
- Vulnerability Analysis
- Exploitation
- Post-Exploitation
- Reporting

## Skills Practiced

- Engagement Planning
- Professional Pentesting Workflow
- Reporting

## Key Takeaways

- One of the most practical penetration testing methodologies.
- Covers the complete engagement lifecycle.
- Excellent framework for real-world penetration testing.
