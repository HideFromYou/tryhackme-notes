# Delivery

## Overview

Delivery is the stage where the prepared payload reaches the target using an appropriate attack vector.

## Learning Objectives

- Identify common delivery methods
- Understand attack vectors
- Recognize phishing and web-based delivery

## Common Delivery Methods

- Phishing Emails
- Malicious Websites
- USB Devices
- File Downloads
- Network Services

## Skills Practiced

- Attack Vector Analysis
- Initial Delivery Techniques

## Key Takeaways

- Delivery bridges preparation and exploitation.
- User awareness is an important defensive control.
