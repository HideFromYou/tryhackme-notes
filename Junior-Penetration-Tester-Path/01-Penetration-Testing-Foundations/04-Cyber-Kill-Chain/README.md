# Cyber Kill Chain

## Overview

The Cyber Kill Chain is a security framework developed to describe the stages of a cyber attack. Understanding each phase helps defenders detect attacks early and enables penetration testers to emulate realistic adversary behaviour during security assessments.

## Learning Objectives

- Understand the Cyber Kill Chain model
- Identify each phase of an attack
- Recognize attacker objectives
- Understand defensive opportunities

## Key Takeaways

- Every cyber attack follows a lifecycle.
- Interrupting any stage can stop the attack.
- Understanding attacker methodology improves both offensive and defensive security.
