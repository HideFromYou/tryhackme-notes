# Command and Control (C2)

## Overview

Command and Control (C2) enables attackers to communicate with compromised systems, execute commands remotely, and manage infected hosts throughout an attack.

## Learning Objectives

- Understand Command and Control
- Recognize common C2 communication channels
- Learn why attackers require remote control

## Common C2 Channels

- HTTP / HTTPS
- DNS
- Reverse Shells
- Encrypted Connections
- Beaconing

## Skills Practiced

- C2 Concepts
- Network Analysis
- Threat Detection

## Key Takeaways

- C2 maintains communication between attacker and victim.
- Detecting unusual outbound traffic is an effective defensive strategy.
- Blocking C2 traffic can interrupt the attack lifecycle.
