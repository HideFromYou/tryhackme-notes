# Installation

## Overview

After successful exploitation, attackers often establish persistence to maintain long-term access to the compromised system, even after reboots or password changes.

## Learning Objectives

- Understand persistence techniques
- Learn why attackers install backdoors
- Recognize common persistence mechanisms

## Common Persistence Techniques

- Backdoors
- Scheduled Tasks
- Startup Services
- Registry Modifications
- Web Shells

## Skills Practiced

- Persistence Concepts
- Attack Lifecycle Analysis
- Defensive Awareness

## Key Takeaways

- Persistence allows attackers to regain access after the initial compromise.
- Monitoring system changes helps detect unauthorized persistence.
- Removing persistence is essential during incident response.
