# Reconnaissance

## Overview

Reconnaissance is the information-gathering phase where attackers collect data about the target before launching an attack.

## Learning Objectives

- Understand passive and active reconnaissance
- Identify information sources
- Build a target profile

## Common Activities

- OSINT
- DNS Enumeration
- WHOIS Lookup
- Network Scanning
- Employee Enumeration

## Skills Practiced

- Information Gathering
- OSINT
- Target Profiling

## Key Takeaways

- Better reconnaissance increases attack success.
- Public information can expose valuable intelligence.
