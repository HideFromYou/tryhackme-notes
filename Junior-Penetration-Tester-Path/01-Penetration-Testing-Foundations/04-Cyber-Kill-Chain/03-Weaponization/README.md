# Weaponization

## Overview

Weaponization combines an exploit with a malicious payload to prepare for delivery to the target.

## Learning Objectives

- Understand payload creation
- Learn how exploits are prepared
- Recognize attacker preparation

## Common Components

- Exploit
- Payload
- Malware
- Social Engineering Content

## Skills Practiced

- Exploit Preparation
- Payload Concepts
- Attack Planning

## Key Takeaways

- Weaponization happens before interacting with the victim.
- Attackers customize payloads for their targets.
