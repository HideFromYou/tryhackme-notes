# Support

## Overview

**Support** is a practical TryHackMe challenge that focuses on assessing a web application's support functionality from a penetration tester's perspective. The objective is to identify security weaknesses within the application's implementation, analyse authentication and authorisation mechanisms, and apply the knowledge gained throughout the Web Application Vulnerabilities II module to compromise the target in a controlled environment.

Rather than introducing new vulnerability classes, this challenge reinforces previously learned concepts by requiring a structured methodology during assessment.

---

## Learning Objectives

After completing this room, you should be able to:

- Perform systematic web application reconnaissance
- Analyse authentication and authorisation mechanisms
- Identify insecure application functionality
- Combine multiple web application testing techniques
- Apply a structured penetration testing methodology

## Key Takeaways

- Effective web application testing follows a structured methodology rather than random testing.
- Authentication and authorisation should always be evaluated independently.
- Multiple low-risk issues may combine into a more significant security vulnerability.
- Careful observation of application behaviour often reveals hidden attack surfaces.
- Practical challenge rooms reinforce both technical knowledge and penetration testing methodology.
