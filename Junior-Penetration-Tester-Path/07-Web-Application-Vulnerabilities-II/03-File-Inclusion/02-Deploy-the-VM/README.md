# Deploy the VM

## Overview

This lesson prepares the practical environment used throughout the File Inclusion room. The virtual machine contains intentionally vulnerable web applications that demonstrate Path Traversal, Local File Inclusion (LFI), and Remote File Inclusion (RFI) in a safe, isolated environment.

The purpose of this lab is to provide a controlled setting where file inclusion vulnerabilities can be analysed and understood without affecting production systems.

---

## Learning Objectives

After completing this lesson, you should be able to:

- Deploy the File Inclusion laboratory environment
- Access the vulnerable web application
- Prepare the environment for practical exercises
- Verify that the laboratory is functioning correctly
- Begin testing file inclusion vulnerabilities safely

---

## Main Content

### Deploying the Virtual Machine

The first step is to deploy the provided virtual machine using the TryHackMe platform.

Once started, the VM hosts several intentionally vulnerable web applications that will be used throughout the remaining lessons.

---

### Accessing the Laboratory

After the virtual machine is running, navigate to the application using the assigned machine IP address.

The laboratory contains multiple scenarios covering different types of file inclusion vulnerabilities, each designed to reinforce a specific concept.

---

### Laboratory Purpose

The practical environment allows learners to:

- Observe vulnerable application behaviour
- Analyse how file inclusion occurs
- Practice identifying vulnerable parameters
- Apply exploitation techniques in a controlled setting
- Reinforce theoretical concepts through hands-on exercises

---

### Preparing for the Next Lessons

The deployed VM will be used throughout the remainder of the room.

Subsequent lessons build upon this environment to demonstrate:

- Path Traversal
- Local File Inclusion (LFI)
- Remote File Inclusion (RFI)
- Practical exploitation
- Defensive techniques
