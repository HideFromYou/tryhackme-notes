# Password Attacks

## Overview

Passwords remain one of the most common methods of authentication and, consequently, one of the primary targets during penetration testing. Weak passwords, password reuse, poor user awareness, and insecure authentication mechanisms often provide attackers with an initial foothold into an organization's environment.

This module introduces the techniques used to obtain credentials through **social engineering**, **online password attacks**, **wordlists**, and **offline password cracking**. Alongside offensive techniques, it also covers defensive measures that help organizations strengthen authentication security.

The module consists of four rooms:

- **01 – Phishing Basics**
- **02 – Hydra**
- **03 – Introduction to Wordlists**
- **04 – Password Cracking**

Together, these topics provide a solid foundation for understanding how credentials are targeted throughout a penetration test.

---

## Learning Objectives

After completing this module, you should be able to:

- Understand common password attack techniques
- Explain how phishing campaigns obtain user credentials
- Perform online password attacks using Hydra
- Build and customize wordlists for password attacks
- Understand offline password cracking concepts
- Apply defensive measures against credential attacks

## Key Takeaways

- Human users are often the weakest link in authentication security.
- Phishing remains one of the most effective methods for obtaining credentials.
- Online password attacks exploit weak or reused passwords.
- Strong wordlists significantly improve password attack effectiveness.
- Secure password policies, MFA, user awareness, and account protection greatly reduce the success of credential attacks.
