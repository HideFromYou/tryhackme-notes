# Stack Fingerprinting

## Overview

This room focuses on **Stack Fingerprinting**, a fundamental reconnaissance technique used to identify the technologies powering modern web applications. By analysing HTTP responses, framework-specific behaviour, and server characteristics, security professionals can accurately determine an application's technology stack before conducting vulnerability assessments.

The room demonstrates fingerprinting techniques across several widely used web application stacks and highlights the importance of combining manual analysis with automated tools.

---

## Learning Objectives

- Understand the purpose of stack fingerprinting
- Identify common web application frameworks
- Analyse HTTP headers and server responses
- Recognise framework-specific indicators
- Perform automated technology identification
- Develop an evidence-based reconnaissance methodology
