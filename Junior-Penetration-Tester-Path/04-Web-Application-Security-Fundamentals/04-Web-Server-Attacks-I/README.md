# Web Server Fingerprinting

## Overview

This room introduces the fundamentals of **Web Server Fingerprinting**, focusing on identifying common web server technologies through passive reconnaissance techniques. By analysing HTTP responses, response headers, default behaviours, and configuration characteristics, security professionals can accurately determine the server software before beginning vulnerability assessments.

The room also explores common misconfigurations that affect multiple web server platforms and demonstrates why proper server hardening is essential.

---

## Learning Objectives

- Understand the role of web servers
- Identify common web server software
- Analyse HTTP response headers
- Perform passive server fingerprinting
- Recognise common configuration weaknesses
- Understand general web server hardening practices

## Key Takeaways

- Web server identification is an essential reconnaissance skill.
- HTTP response headers often reveal valuable technology information.
- Different web servers share many common security weaknesses.
- Proper configuration is more important than default installations.
- Passive reconnaissance provides the foundation for effective security assessments.
