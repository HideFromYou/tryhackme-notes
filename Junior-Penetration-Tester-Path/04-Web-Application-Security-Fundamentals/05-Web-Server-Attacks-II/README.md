# Attacking IIS

## Overview

This room focuses on **Microsoft Internet Information Services (IIS)** and the techniques used to identify, enumerate, and assess Windows-based web servers. It introduces IIS-specific technologies such as WebDAV, Windows authentication, ASP.NET, and legacy filename handling while demonstrating how structured reconnaissance improves security assessments.

The room also highlights common IIS misconfigurations and shows how automated tools can complement manual enumeration.

---

## Learning Objectives

- Understand Microsoft IIS architecture
- Fingerprint IIS web servers
- Identify Windows authentication mechanisms
- Understand WebDAV functionality
- Recognise common IIS misconfigurations
- Perform automated IIS enumeration

## Key Takeaways

- IIS is the primary web server platform for Windows environments.
- IIS-specific technologies require specialised reconnaissance techniques.
- Proper enumeration reveals valuable configuration and authentication information.
- Automation accelerates reconnaissance while manual validation improves accuracy.
- Secure IIS deployments depend on proper configuration, least privilege, and continuous hardening.
