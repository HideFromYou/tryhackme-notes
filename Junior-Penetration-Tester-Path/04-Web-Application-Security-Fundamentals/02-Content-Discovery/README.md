# Content Discovery

## Overview

This room introduces the fundamentals of **Content Discovery**, an essential phase of web application reconnaissance. Before attempting to identify vulnerabilities, security professionals must first understand the application's structure, technologies, and publicly accessible resources.

The room covers three complementary approaches:

- Manual Discovery
- Open-Source Intelligence (OSINT)
- Automated Discovery

Together, these techniques help build a comprehensive view of the application's attack surface.

---

## Learning Objectives

- Understand the purpose of content discovery
- Perform manual web application reconnaissance
- Identify useful public resources
- Apply OSINT techniques
- Enumerate hidden content using automated tools
- Discover subdomains and virtual hosts
- Develop a structured reconnaissance workflow

## Key Takeaways

- Effective penetration testing begins with thorough reconnaissance.
- Manual discovery often reveals valuable information with minimal effort.
- OSINT provides additional intelligence without directly interacting with the target.
- Automated enumeration significantly expands discovery coverage.
- Combining multiple reconnaissance techniques results in a more complete understanding of the application's attack surface.
- A well-executed content discovery phase improves the efficiency and accuracy of subsequent security assessments.
