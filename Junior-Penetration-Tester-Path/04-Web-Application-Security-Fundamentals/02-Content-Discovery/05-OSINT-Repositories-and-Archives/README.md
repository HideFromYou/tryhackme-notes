# OSINT - Repositories & Archives

## Overview

Beyond search engines, several public platforms preserve historical web content or host publicly accessible source code. These resources often reveal information that is no longer visible on a live website but remains valuable during reconnaissance.

---

## Learning Objectives

- Understand the value of historical web archives
- Learn how public repositories support reconnaissance
- Identify publicly exposed cloud storage
- Discover information useful for later testing

---

## Internet Archives

Historical web archives store snapshots of websites captured over time.

These snapshots may contain:

- Old login portals
- Deprecated pages
- Previous application versions
- Removed documentation
- Legacy API endpoints

Comparing archived content with the current website helps identify changes and forgotten resources.

---

## Wayback Machine

The Wayback Machine is one of the most widely used web archives.

Security professionals use it to:

- Review historical versions of websites
- Discover removed pages
- Locate deprecated content
- Compare application changes over time

Archived content may reveal information no longer available on the live application.

---

## Public Code Repositories

Many organisations publish code through version control platforms.

Public repositories may contain:

- Documentation
- Configuration examples
- Source code
- Development notes
- Deployment scripts

Reviewing repository history can provide additional context about how an application is built.

---

## Repository History

Version control systems preserve previous revisions of files.

Examining commit history may reveal:

- Removed configuration files
- Previous application behaviour
- Development changes
- Accidentally published information

Historical commits often contain data that no longer exists in the latest version.

---

## Cloud Storage

Many organisations use cloud storage services to host assets and application files.

Publicly accessible storage may contain:

- Images
- Documents
- Backups
- Static website content
- Application resources

Misconfigured storage permissions can unintentionally expose information.

---

## Skills Practiced

- OSINT research
- Historical website analysis
- Repository inspection
- Cloud storage reconnaissance

---

## Key Takeaways

- Historical archives preserve valuable reconnaissance data.
- Public repositories provide insight into application development.
- Commit history can expose previously published information.
- Cloud storage should be considered during reconnaissance.
- Combining multiple OSINT sources improves overall visibility.
