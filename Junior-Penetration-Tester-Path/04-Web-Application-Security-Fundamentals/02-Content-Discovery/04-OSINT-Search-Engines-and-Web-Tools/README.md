# OSINT - Search Engines & Web Tools

## Overview

Open-Source Intelligence (OSINT) uses publicly available information to gather intelligence about a target. Search engines and specialised web tools can reveal technologies, indexed resources, and publicly exposed information without interacting directly with the application.

---

## Learning Objectives

- Understand the role of OSINT
- Learn basic search engine reconnaissance
- Discover technology fingerprinting tools
- Identify publicly available information

---

## What is OSINT?

OSINT refers to collecting information from publicly accessible sources.

Examples include:

- Search engines
- Public websites
- Documentation
- Technology fingerprinting tools
- Public databases

OSINT allows analysts to gather valuable intelligence before active testing begins.

---

## Search Engine Operators

Search engines support advanced operators that refine search results.

Common examples include:

- `site:`
- `inurl:`
- `intitle:`
- `intext:`
- `filetype:`
- `cache:`

These operators help locate specific resources associated with a target domain.

---

## Google Dorking

Combining multiple search operators can uncover:

- Login portals
- Public documents
- Administrative pages
- Configuration files
- Backup files
- Exposed content

Only publicly indexed information is queried, making this a passive reconnaissance technique.

---

## Technology Fingerprinting

Identifying the technologies behind a website provides valuable context.

Information commonly discovered includes:

- CMS platforms
- JavaScript frameworks
- Analytics services
- Web servers
- Content Delivery Networks (CDNs)
- Programming languages

Technology fingerprinting supports later vulnerability research.

---

## Wappalyzer

Wappalyzer is a popular browser extension that detects technologies used by websites.

It can identify:

- Frameworks
- CMS platforms
- Libraries
- Hosting providers
- Analytics tools
- Payment services

This information helps build a profile of the application's technology stack.

## Key Takeaways

- OSINT collects information without interacting directly with the target.
- Search operators improve reconnaissance efficiency.
- Technology fingerprinting identifies application components.
- Publicly available information often supports later testing.
- Passive reconnaissance reduces noise while providing valuable intelligence.
