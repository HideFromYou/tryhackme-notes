# Wireless Security — Introduction

## Wireless Frequency Spectrum

Wireless technologies communicate using radio frequencies. Common technologies covered in this room include:

- RFID — approximately 125 KHz to 960 MHz
- NFC — 13.56 MHz
- Bluetooth — 2.4 GHz
- Wi-Fi — 2.4 GHz and 5 GHz

Bluetooth and Wi-Fi can operate in the same 2.4 GHz band, which can result in interference.

## Why Wireless Security Matters

Wireless technologies allow devices to communicate without physical connections, but the radio-based nature of these technologies introduces additional security risks.

Attackers may exploit weaknesses in wireless protocols, configurations, authentication mechanisms, or exposed radio communication to compromise sensitive information or gain access to systems.

Understanding how wireless technologies operate is therefore an important foundation for assessing wireless security.

## Learning Objectives

- Understand the fundamentals of wireless networking and radio-frequency communication
- Identify common wireless technologies and their use cases
- Recognise common security risks and attack vectors
- Understand basic measures used to protect wireless networks

## Technologies Covered

### Wi-Fi

Wireless LAN technology based on IEEE 802.11 standards.

Commonly operates on:

- 2.4 GHz
- 5 GHz

### Bluetooth

Short-range wireless technology used for device pairing and data exchange.

Operates on:

- 2.4 GHz

### NFC

Near-field communication used for short-range data exchange and contactless interactions.

Operates on:

- 13.56 MHz

### RFID

Radio-frequency identification technology used for identification and tracking.

Depending on the implementation, RFID can operate across a range of frequencies.

## Key Takeaway

Wireless communication removes the requirement for physical network connections, but it also creates a different attack surface.

A security assessment should therefore consider:

- The wireless technology being used
- Its operating frequency
- Authentication mechanisms
- Encryption
- Device exposure
- Possible interference
- Wireless-specific attack vectors
