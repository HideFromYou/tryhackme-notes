## Key Terms

- **SSID** — Service Set Identifier, the human-readable name of a Wi-Fi network.
- **BSSID** — Basic Service Set Identifier, normally the MAC address of a wireless access point.
- **WEP** — Legacy Wi-Fi security protocol with fundamental cryptographic weaknesses.
- **WPA** — Wireless security protocol introduced as a replacement for WEP.
- **WPA2** — Wi-Fi security protocol using AES encryption.
- **WPA3** — Successor to WPA2 using SAE for stronger authentication.
- **MITM** — Man-in-the-Middle attack.
- **SAE** — Simultaneous Authentication of Equals.
- **BLE** — Bluetooth Low Energy.
- **SSP** — Secure Simple Pairing.
- **RFID** — Radio-Frequency Identification.
- **NFC** — Near-Field Communication.
- **Zigbee** — Low-power wireless mesh protocol.
- **Z-Wave** — Wireless protocol commonly used in home automation.
- **LoRa** — Long Range, low-power wireless technology.
- **Infrared** — Short-range line-of-sight wireless communication using light.

Wireless security requires understanding both how a technology operates and how its design can introduce security weaknesses.
