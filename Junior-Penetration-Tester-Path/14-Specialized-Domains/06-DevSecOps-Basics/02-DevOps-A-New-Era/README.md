# 02 - DevOps: A New Era

## Overview

This lesson explains the evolution from Waterfall to Agile and finally DevOps.

The main problem being addressed throughout this evolution is the lack of flexibility, communication, and collaboration between teams.

---

## Waterfall Model

The Waterfall model follows a sequential approach.

Different teams have clearly separated responsibilities:

    Developers
        ↓
    Development

    Sysadmins
        ↓
    Operations

    QA
        ↓
    Testing

Each team performs its part of the process.

---

## Problems with Waterfall

When something goes wrong, responsibility can move between teams.

For example:

    Bug
      ↓
    Who fixes it?
      ↓
    Developers?
    Sysadmins?
    QA?

This can lead to:

    Blame
    Backlogs
    Delays
    Communication Gaps
    Friction
    Unresolved Bugs
    Unresolved Security Flaws

As releases and customer expectations increase, this model becomes difficult to scale.

---

## Agile Model

Agile emerged to provide more flexibility and adaptability.

The Agile Manifesto emphasises four values:

    Individuals and interactions
        over
    Processes and tools

    Working software
        over
    Comprehensive documentation

    Customer collaboration
        over
    Contract negotiation

    Responding to change
        over
    Following a plan

Agile encourages collaboration, self-organising teams, customer focus, and flexibility.

---

## DevOps

DevOps developed from the limitations of previous methodologies.

The main focus is:

    Cultural Change
    Integration
    Automation
    Collaboration

Instead of keeping teams isolated:

    Developers
    QA
    Sysadmins

DevOps encourages them to work together.

---

## Integration and Automation

DevOps brings different teams closer together.

For example:

    Developers
        ↕
    QA
        ↕
    Sysadmins

Automation allows teams to share visibility and perform tasks more efficiently.

This includes:

    CI/CD
    Automation
    Infrastructure as Code
    Automated Environments

---

## Why DevOps Is Important

DevOps emphasises:

    Building Trust
    Better Communication
    Collaboration
    Small Changes
    Reversible Changes
    Shared Visibility

This helps organisations align technology with business requirements.

---

## Modern DevOps Infrastructure

Modern DevOps environments can provide:

    Automated Infrastructure
    Self-Service Resources
    CI/CD
    Automated Testing
    Cloud Environments
    Infrastructure as Code
    Containers

---

## Key Takeaways

- Waterfall is sequential and highly separated.
- Waterfall can create communication gaps and friction.
- Agile introduced greater flexibility and collaboration.
- DevOps focuses on cultural change.
- DevOps combines integration and automation.
- DevOps aims to build trust between teams.
