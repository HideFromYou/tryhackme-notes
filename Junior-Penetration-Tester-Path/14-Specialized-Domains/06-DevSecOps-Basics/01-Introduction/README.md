# 01 - Introduction

## Overview

This lesson introduces the evolution of software development practices and explains how these changes led to DevSecOps.

The main idea is that software development has evolved from isolated and sequential processes towards collaborative, automated, and security-aware development.

---

## Learning Objectives

- Understand the history and evolution of software development practices.
- Understand why these changes were necessary.
- Understand the importance of DevSecOps.
- Understand DevSecOps as both a culture and a discipline.

## Core Idea

The evolution of software development changed the way security must be approached.

Security can no longer be treated as something performed only at the end of development.

Instead:

    Development
        ↓
    Operations
        ↓
    Automation
        ↓
    Security Integration
        ↓
    DevSecOps
