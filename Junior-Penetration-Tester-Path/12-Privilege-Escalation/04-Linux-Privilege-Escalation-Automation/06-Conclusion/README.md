# Conclusion

## Overview

This room demonstrated how automation enhances Linux privilege escalation by accelerating enumeration, identifying common misconfigurations, and assisting with exploit research.

Rather than replacing manual investigation, automated tools improve efficiency while leaving the final analysis and exploitation decisions to the penetration tester.

## Key Takeaways

- Automation accelerates privilege escalation but does not replace understanding.
- Enumeration tools should be used to support—not replace—manual analysis.
- Public exploits require validation before execution.
- pspy provides valuable visibility into privileged processes without requiring root access.
- The next room transitions from Linux to **Windows Privilege Escalation**, applying similar enumeration and exploitation methodology within the Windows operating system.
