# Challenge

## Overview

This challenge combines manual enumeration, automated enumeration, process monitoring, and exploit research into a complete Linux privilege escalation assessment.

Rather than relying on a single technique, the objective is to identify, validate, and exploit a realistic privilege escalation path.

---

## Learning Objectives

- Apply automated enumeration
- Validate findings manually
- Use pspy effectively
- Research public exploits
- Obtain root privileges

---

## Suggested Methodology

```text
Gain Initial Access
        ↓
Manual Enumeration
        ↓
Run Enumeration Tools
        ↓
Monitor Processes
        ↓
Validate Findings
        ↓
Research Public Exploits
        ↓
Privilege Escalation
        ↓
Root Shell
```

---

## Skills Practiced

- Linux Enumeration
- LinPEAS
- Searchsploit
- pspy
- Process Analysis
- Privilege Escalation

---

## Key Takeaways

- Multiple enumeration techniques provide better coverage than relying on a single tool.
- Every automated finding should be investigated manually.
- Combining enumeration with process monitoring often reveals privilege escalation vectors that would otherwise remain hidden.
