# Practical

## Overview

This practical exercise applies the concepts introduced throughout the room by reviewing host configurations and identifying security weaknesses against recognised configuration baselines.

The objective is to build familiarity with structured configuration reviews before moving into privilege escalation techniques.

---

## Learning Objectives

- Review host configurations
- Apply security baselines
- Identify misconfigurations
- Prioritise findings

---

## Practical Workflow

```text
Identify Host
       ↓
Review Configuration
       ↓
Compare Against Baseline
       ↓
Identify Weaknesses
       ↓
Assess Security Impact
```

---

## Skills Practiced

- Configuration Reviews
- CIS Benchmark Interpretation
- Host Enumeration
- Security Assessment

---

## Key Takeaways

- Practical reviews reinforce the importance of systematic host enumeration.
- Security baselines provide measurable expectations for secure configurations.
- Misconfigurations frequently represent realistic privilege escalation opportunities.
